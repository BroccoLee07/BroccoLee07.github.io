Kitchen Chaos (Reworked)

Smart Job Scraper

Smart Job Scraper is a Python automation tool and local dashboard for finding, filtering, reviewing, and exporting job opportunities. It pulls from multiple job-board and ATS sources, applies configurable search rules, and exports reviewed results to JSON, CSV, Excel, SQLite, and Google Sheets.

The project showcases AI-assisted review with LLM enrichment through OpenAI-compatible providers and local Ollama models, with deterministic fallback scoring when AI is unavailable. It also includes Playwright-powered automation support, pytest and Ruff coverage, plus GitHub Actions workflows for CI checks and scheduled scraping/export runs.
